# Abdulaziz Alkhlaiwe portfolio

A static portfolio for Abdulaziz Alkhlaiwe, built from the verified copy in `content/content.json` and served from the repository root on GitHub Pages.

## Build

Use Node.js 20 or newer. Run `npm run build` to render `src/template.html` into the committed `index.html`.

## Deploy

Publish the `main` branch from the repository root in GitHub Pages settings. The page uses relative asset URLs and is designed for the `/Abdulaziz/` project path.
